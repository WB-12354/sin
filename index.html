Kodi Add-on for Live TV & Catchup

Add this URL to your Kodi File Manager:

https://wb-12354.github.io/sin/
Download Zip View on GitHub

How to Install in Kodi

  1. Open Kodi and go to Settings (gear icon).
  2. Select File Manager > Add source.
  3. Enter the URL exactly as: https://wb-12354.github.io/sin/ and name it JioTV Repo.
  4. Go back to the main menu and select Add-ons.
  5. Click the open box icon (Package Installer) at the top left.
  6. Select Install from zip file.
  7. Choose JioTV Repo and install the zip file.
